With this module, when a user make a payment that triggers an exchange
rate move, the module will define the analytic account in the exchange
move line.

**Table of contents**

.. contents::
   :local:

Configuration
=============

Yoy don't need to do anything, the module will do it for you.

Usage
=====

Only pay an invoice with analytic account defined if there is need of an
exchange rate move it will be created with analytic account defined in
the move line.
